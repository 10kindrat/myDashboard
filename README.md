# 개인 대시보드 (myDashboard)

개인용 웹 대시보드 프로젝트입니다. 할 일 관리, 메모, 일정 확인, 아날로그/디지털 시계를 한 화면에서 볼 수 있습니다.

## 주요 기능

- **할 일 목록** — 할 일 추가 및 클릭으로 삭제, `localStorage`에 자동 저장
- **아날로그 시계** — 시/분/초침이 실시간으로 움직이는 시계
- **디지털 시계** — `HH:MM:SS` 형식의 현재 시각 표시
- **메모 / 일정 카드** — 추후 기능 확장을 위한 영역

## 파일 구조

```
├── index.html    # 메인 HTML 구조
├── css/
│   └── style.css # 스타일시트
├── js/
│   └── script.js # 할 일 목록 및 시계 로직
└── README.md
```
